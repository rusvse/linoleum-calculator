# Линум — сервис расчёта линолеума

Первая версия рассчитывает линолеум по квартирам и помещениям: размеры с запасом, подходящую ширину рулона, полосы, стыки, погонные метры, закупаемую площадь и отходы. Данные сохраняются в браузере автоматически.

## Запуск сайта через GitHub Pages

1. В репозитории откройте **Settings → Pages**.
2. В **Build and deployment** выберите `Deploy from a branch`.
3. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
4. После публикации добавьте в поле **Custom domain** адрес `linum.anvaska.ru`.

## Подключение linum.anvaska.ru в REG.RU

В панели REG.RU откройте домен `anvaska.ru` → управление DNS-зоной → добавить запись:

| Поле | Значение |
|---|---|
| Тип | `CNAME` |
| Имя / поддомен | `linum` |
| Значение | `rusvse.github.io.` |

Не создавайте для `linum` дополнительные A/AAAA/CNAME-записи. Подождите распространения DNS, затем в GitHub Pages включите **Enforce HTTPS**.

## Выгрузка в Google Таблицы

GitHub Pages — статический сайт, поэтому для создания таблиц используется Google Apps Script.

1. Откройте [script.google.com](https://script.google.com) под нужным Google-аккаунтом и создайте проект.
2. Замените содержимое файла `Code.gs` кодом из `google-apps-script/Code.gs` этого репозитория.
3. Нажмите **Deploy → New deployment**.
4. Выберите тип **Web app**.
5. В поле **Execute as** выберите `Me`.
6. В поле доступа выберите вариант, который разрешает выполнение пользователям сайта (для личного применения — только вашему аккаунту; для общего доступа — Anyone).
7. Нажмите **Deploy**, подтвердите разрешения Google и скопируйте URL веб-приложения, который оканчивается на `/exec`.
8. На сайте вставьте этот URL в поле **URL Google Apps Script**, сохраните параметры и нажмите **Выгрузить в Google Таблицы**.

Будет создана таблица с листами **Помещения**, **Расчёт** и **Заказ**.

## Ограничения первой версии

- Логика подбирает раскрой каждого помещения отдельно.
- Остатки между помещениями и подбор рисунка будут добавлены во второй версии.
- Для помещения можно использовать несколько полос; при этом показывается число стыков.
- Для режима «минимум стыков» приоритет — меньше полос, затем меньше отходов. Для «минимум отходов» — наоборот.
