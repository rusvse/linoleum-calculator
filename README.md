# Линум — сервис расчёта линолеума

Сайт рассчитывает линолеум по квартирам и помещениям: размеры с запасом, ширину рулона, полосы, стыки, погонные метры, закупаемую площадь и отходы. Данные автоматически сохраняются в браузере.

## Как устроена выгрузка

После настройки Google Apps Script при первой выгрузке создаётся одна постоянная Google Таблица с названием **«Расчёты линолеума»**.

При каждом последующем нажатии кнопки **Выгрузить в Google Таблицы** сайт добавляет в эту же таблицу **один новый лист**. Название листа — точные дата и время расчёта, например:

```text
06.08.2026 15-54-20
```

На одном листе последовательно размещаются три блока: **Помещения**, **Расчёт** и **Сводка заказа**. Новые отдельные таблицы и три отдельных листа не создаются.

## Скачать без Google Таблиц

Кнопка **Скачать CSV** формирует и скачивает полный расчёт на компьютер. Она работает даже без подключения Google Apps Script и Google Таблиц. CSV можно открыть в Excel, LibreOffice Calc или импортировать в Google Таблицы вручную.

## Настройка Google Apps Script

### 1. Откройте Apps Script

1. Откройте [Google Apps Script](https://script.google.com).
2. Войдите в Google-аккаунт, в котором хотите хранить итоговую таблицу.
3. Нажмите **Новый проект (New project)**.
4. Вверху слева нажмите **Проект без названия (Untitled project)** и назовите его `Линум — выгрузка расчётов`.

### 2. Скопируйте код из GitHub

1. Откройте репозиторий `rusvse/linoleum-calculator` на GitHub.
2. Откройте папку `google-apps-script`.
3. Нажмите файл `Code.gs`.
4. Нажмите кнопку **Raw**.
5. Выделите код полностью: Windows — `Ctrl + A`, затем `Ctrl + C`; Mac — `Cmd + A`, затем `Cmd + C`.
6. Вернитесь на вкладку Google Apps Script.
7. Слева в разделе **Файлы (Files)** откройте `Code.gs`.
8. Удалите стандартный текст: `Ctrl + A` / `Cmd + A`, затем `Delete`.
9. Вставьте скопированный код: `Ctrl + V` / `Cmd + V`.
10. Нажмите **Сохранить проект (Save project)** или `Ctrl + S` / `Cmd + S`.

### 3. Разверните веб-приложение

1. Вверху справа нажмите **Развернуть (Deploy)**.
2. Выберите **Новое развёртывание (New deployment)**.
3. Нажмите значок шестерёнки в поле выбора типа и выберите **Веб-приложение (Web app)**.
4. В поле **Описание (Description)** напишите `Линум — выгрузка`.
5. В поле **Выполнять от имени (Execute as)** выберите **Я (Me)**. Тогда таблица будет создаваться и храниться именно в вашем Google Диске.
6. В поле **Кто имеет доступ (Who has access)** выберите доступный вариант. Для личного использования выбирайте самый ограниченный вариант, который позволяет открыть веб-приложение в браузере под вашим Google-аккаунтом.
7. Нажмите **Развернуть (Deploy)**.
8. Если Google запросит права, нажмите **Авторизовать доступ (Authorize access)**, выберите ваш аккаунт и подтвердите разрешение на создание и редактирование Google Таблиц.
9. Если появится предупреждение «Google не проверил это приложение», нажмите **Дополнительно (Advanced)** → **Перейти к проекту … (Go to …)** → **Разрешить (Allow)**.
10. В финальном окне скопируйте **URL веб-приложения (Web app URL)**. Адрес должен оканчиваться на `/exec`.

### 4. Передайте URL для подключения

Не вставляйте URL Apps Script в поле на сайте. Отправьте мне URL, который оканчивается на `/exec`, отдельным сообщением. Я добавлю его в код сайта на GitHub и уберу поле для ручного ввода URL.

Не размещайте этот URL публично: он используется сайтом для отправки расчётов в вашу Google Таблицу.

## Публикация сайта

### GitHub Pages

1. Откройте репозиторий `rusvse/linoleum-calculator`.
2. Нажмите **Настройки (Settings)**.
3. В левом меню откройте **Страницы (Pages)**.
4. В блоке **Сборка и развёртывание (Build and deployment)** выберите **Развёртывать из ветки (Deploy from a branch)**.
5. В поле **Ветка (Branch)** выберите `main`; в соседнем списке выберите `/(root)`.
6. Нажмите **Сохранить (Save)**.

### Поддомен linum.anvaska.ru

1. В GitHub откройте **Settings → Pages**.
2. В поле **Пользовательский домен (Custom domain)** введите `linum.anvaska.ru`.
3. Нажмите **Сохранить (Save)**.
4. В REG.RU откройте `anvaska.ru` → **DNS-серверы и управление зоной** → добавьте запись:

| Поле | Значение |
|---|---|
| Тип | `CNAME` |
| Имя / поддомен | `linum` |
| Значение | `rusvse.github.io.` |
| TTL | По умолчанию |

5. Для `linum` не создавайте дополнительные записи `A`, `AAAA` или второй `CNAME`.
6. После DNS-проверки вернитесь в GitHub Pages и включите **Принудительный HTTPS (Enforce HTTPS)**.

## Как использовать сайт

1. Заполните название проекта, материал, ширины рулонов, запас и режим подбора.
2. Нажмите **Добавить квартиру**.
3. Для квартиры заполните номер и название.
4. Нажмите **Добавить помещение** и выберите тип помещения.
5. Укажите длину и ширину; сервис одинаково понимает `4.25` и `4,25`.
6. Нажмите **Рассчитать**.
7. Проверьте таблицу результатов и сводку заказа.
8. Если нужен файл на компьютер — нажмите **Скачать CSV**.
9. Если нужна запись в Google Таблицу — нажмите **Выгрузить в Google Таблицы**. В постоянной таблице будет добавлен один новый лист с текущими датой и временем.

## Ограничения первой версии

Расчёт делает подбор по каждому помещению отдельно. Использование остатка одного помещения для другого, сложные формы комнат и подбор рисунка будут добавляться во второй версии.
