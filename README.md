# Линум — калькулятор линолеума

Простой веб-инструмент для расчёта нарезки линолеума на квартиры и помещения.

## Функции
- добавление любого числа квартир и помещений;
- расчёт с учётом заданных ширин рулона и запаса на подгонку;
- два режима подбора: минимум стыков или минимум отходов;
- сводная таблица для заказа материала с группировкой по ширине рулона;
- сохранение параметров в localStorage браузера;
- экспорт в CSV;
- печать страницы.

## Файлы
- `index.html` — разметка
- `style.css` — стили
- `app.js` — логика
- `google-apps-script/Code.gs` — вспомогательный скритт для экспорта в Google таблицы
