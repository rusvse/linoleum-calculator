# Линум — калькулятор линолеума

Веб-инструмент для расчёта нарезки линолеума на квартиры и помещения, с архивом расчётов в Google таблице.

## Функции
- добавление любого числа квартир и помещений;
- расчёт с учётом заданных ширин рулона и запаса на подгонку;
- два режима подбора: минимум стыков или минимум отходов;
- сводная таблица для заказа с группировкой по ширине рулона;
- сохранение текущих данных в localStorage браузера;
- кнопка «Очистить всё» для быстрого начала нового расчёта;
- экспорт в CSV и печать страницы;
- **архив в Google таблице**: каждое сохранение через «Выгрузить в Google таблицы» создаёт запись с датой; вы можете выбрать любую дату из списка архива на сайте, загрузить её, отредактировать и сохранить снова как новую запись.

## Файлы
- `index.html` — разметка
- `style.css` — стили
- `app.js` — логика
- `google-apps-script/Code.gs` — скрипт архива в Google таблице

## Настройка архива в Google таблице (один раз)
1. Создайте новую Google таблицу (например, «Линум — архив»).
2. В ней: расширения → Apps Script.
3. Удалите весь код в открывшемся редакторе и вставьте содержимое файла `google-apps-script/Code.gs`.
4. Сохраните проект, затем Наверху справа → «Развернуть» → «Новый развёртывание».
5. Выбрать тип «Веб-приложение». Исполнять от имени: **вы**. Доступ имеют: **Любые**.
6. Нажать «Развернуть», разрешить доступ (придётся подтвердить, что скрипт от неизвестного разработчика — это нормально, это ваш собственный скрипт).
7. Скопируйте полученный URL веб-аппа (вида `https://script.google.com/macros/s/.../exec`).
8. Открыте `app.js`, найдите строку `const APPS_SCRIPT_URL = '';` и вставьте скопированный URL между кавычками. Сохраните и обновите сайт.
9. в таблице автоматически появятся два листа: **Архив** (одна строка на каждое сохранение, с датой и полными данными) и **История** (каждая строка — одно рассчитанное помещение, удобно для чтения и фильтрации прямо в таблице).

После настройки на сайте появится работающий блок «Архив расчётов» с выбором сохранённых дат.
