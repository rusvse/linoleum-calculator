# Линум — сервис расчёта линолеума

Сайт рассчитывает линолеум по квартирам и помещениям: запас, ширину рулона, полосы, стыки, погонные метры, закупаемую площадь и отходы. Данные автоматически сохраняются в браузере.

## Что делает выгрузка

После настройки Google Apps Script создаётся одна таблица **«Расчёты линолеума»**. При каждом новом расчёте сайт не создаёт новую таблицу: он добавляет в эту же таблицу три новых листа с датой и временем, например:

- `Помещения 06.08.2026 13-30-15`
- `Расчёт 06.08.2026 13-30-15`
- `Заказ 06.08.2026 13-30-15`

## Настройка Google Apps Script

### 1. Откройте Apps Script

1. Откройте браузер и перейдите на сайт [Google Apps Script](https://script.google.com).
2. Войдите в тот Google-аккаунт, в котором хотите хранить таблицу.
3. Нажмите **Новый проект (New project)**.
4. В левом верхнем углу нажмите на название «Без названия» и переименуйте проект, например в `Линум — выгрузка расчётов`.

### 2. Вставьте код

1. Слева откройте файл **Code.gs**.
2. Удалите весь стандартный текст в центральном поле.
3. В репозитории GitHub откройте файл `google-apps-script/Code.gs`.
4. Нажмите кнопку **Raw**.
5. Скопируйте весь код: Windows — `Ctrl + A`, затем `Ctrl + C`; Mac — `Cmd + A`, затем `Cmd + C`.
6. Вернитесь на вкладку Google Apps Script, вставьте код: `Ctrl + V` или `Cmd + V`.
7. Нажмите значок сохранения или сочетание `Ctrl + S` / `Cmd + S`.

### 3. Разверните веб-приложение

1. В правом верхнем углу нажмите **Развернуть (Deploy)**.
2. Выберите **Новое развёртывание (New deployment)**.
3. Нажмите на значок шестерёнки рядом с пунктом «Выберите тип» и выберите **Веб-приложение (Web app)**.
4. В поле **Описание (Description)** напишите `Линум — выгрузка`.
5. В поле **Выполнять от имени (Execute as)** выберите **Я (Me)**. Это важно: таблица будет создаваться в вашем Google Диске.
6. В поле **Кто имеет доступ (Who has access)** выберите вариант, доступный в вашем аккаунте для работы с сайта. Если сервис используется только вами, выбирайте самый ограниченный вариант, который позволяет открыть веб-приложение из браузера, где вы вошли в этот Google-аккаунт.
7. Нажмите **Развернуть (Deploy)**.
8. При первом запуске Google покажет окно прав: нажмите **Авторизовать доступ (Authorize access)**, выберите ваш аккаунт и подтвердите разрешение на работу с Google Таблицами.
9. В окне развёртывания скопируйте **URL веб-приложения (Web app URL)**. Он заканчивается на `/exec`.

### 4. Важно: не вставляйте URL сами

Не вставляйте URL Apps Script в какие-либо поля сайта. Отправьте этот URL мне в сообщении. Я добавлю его в код сайта на GitHub, и поля для ссылки на сайте не будет.

Не публикуйте URL в открытых сообщениях или на страницах: через него выполняется выгрузка в вашу таблицу. Для полноценного доступа разных сотрудников с личными Google-аккаунтами потребуется второй этап — авторизация Google OAuth.

## Настройка GitHub Pages

1. Откройте репозиторий `rusvse/linoleum-calculator`.
2. Нажмите **Настройки (Settings)**.
3. В левом меню откройте **Страницы (Pages)**.
4. В блоке **Сборка и развёртывание (Build and deployment)** выберите **Развёртывать из ветки (Deploy from a branch)**.
5. В поле **Ветка (Branch)** выберите `main`, рядом выберите `/(root)`.
6. Нажмите **Сохранить (Save)**.

## Домен linum.anvaska.ru

1. В GitHub на странице **Settings → Pages** в поле **Пользовательский домен (Custom domain)** укажите `linum.anvaska.ru` и нажмите **Сохранить (Save)**.
2. В личном кабинете REG.RU откройте домен `anvaska.ru` → **DNS-серверы и управление зоной** → добавьте ресурсную запись:

| Поле | Значение |
|---|---|
| Тип | `CNAME` |
| Имя / поддомен | `linum` |
| Значение | `rusvse.github.io.` |
| TTL | По умолчанию |

3. Не добавляйте для `linum` другие записи `A`, `AAAA` или `CNAME`.
4. Подождите проверки DNS. Затем в GitHub включите флажок **Принудительный HTTPS (Enforce HTTPS)**.

## Как работать на сайте

1. Заполните название проекта, материал, ширины рулонов, запас и режим подбора.
2. Нажмите **Добавить квартиру**.
3. Внутри квартиры нажмите **Добавить помещение** и укажите тип, длину и ширину. Точка и запятая в размерах равнозначны.
4. Нажмите **Рассчитать**.
5. Проверьте таблицу результатов и сводку заказа.
6. Нажмите **Выгрузить в Google Таблицы**. В одной таблице появятся три новых листа с текущими датой и временем.

## Ограничения первой версии

Расчёт делает подбор для каждого помещения отдельно. Использование остатков от одного помещения в другом, раскрой сложных форм и подбор рисунка относятся ко второй версии.
