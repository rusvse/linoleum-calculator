# Линум — калькулятор линолеума

Веб-инструмент для расчёта нарезки линолеума на квартиры и помещения, с архивом расчётов в Google таблице и встроенной инструкцией.

## Функции
- добавление любого числа квартир и помещений;
- расчёт с учётом заданных ширин рулона и запаса на подгонку;
- два режима подбора: минимум стыков или минимум отходов;
- сводная таблица для заказа с группировкой по ширине рулона;
- сохранение текущих данных в localStorage браузера;
- кнопка «Очистить всё» для быстрого начала нового расчёта;
- экспорт в CSV и печать страницы;
- архив в Google таблице с возможностью загрузки старых расчётов;
- страница «Инструкция» с объяснением методики расчёта и готовым примером.

## Файлы
- `index.html` — разметка калькулятора
- `instructions.html` — страница инструкции
- `style.css` — стили
- `app.js` — логика
- `google-apps-script/Code.gs` — скрипт архива в Google таблице
