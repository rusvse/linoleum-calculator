Калькулятор Инструкция

1. Как работать с калькулятором

  1. Название проекта — произвольное название, по которому вы будете узнавать расчёт в архиве Google таблицы.
  2. Линолеум / артикул — название или артикул материала, попадает в архив вместе с расчётом.
  3. Ширины рулонов, м — список всех доступных вам ширин рулона линолеума в метрах, через запятую (например, 2, 2.5, 3, 3.5, 4, 5). Калькулятор сам выберет подходящую ширину из этого списка для каждого помещения.
  4. Запас с каждой стороны, см — технологический запас (на усадку, подгонку рисунка и т.п.), который добавляется к каждой из двух сторон помещения (то есть к длине и ширине добавляется по два запаса — с обоих краев).
  5. Режим подбора — что важнее для вас: минимум стыков (меньше стыков на полу, даже если останется больше обрезка) или минимум отходов (меньше лишнего материала).
  6. Далее добавляете квартиры и в каждой — помещения: выбираете тип помещения (или своё через «Своё...») и указываете длину и ширину в метрах (дробная часть вводится с завёатой или точкой: 4,20 или 4.20).
  7. Кнопками «Копировать» у квартиры или помещения вы создаёте точную копию со всеми значениями — удобно, если много одинаковых квартир.
  8. Нажимаете кнопку «Рассчитать». Калькулятор проверяет все заведённые данные и выводит результат двумя таблицами ниже: подробной по каждому помещению и сводкой для заказа.

2. Методика расчёта и формулы

Обозначения:

  • L, W — длина и ширина помещения, как введены (в метрах).
  • a — заданный запас в сантиметрах, переведённый в метры: a_m = a_cm / 100.
  • L′, W′ — размеры с учётом запаса с обеих сторон:
    L′ = L + 2 × a_m   W′ = W + 2 × a_m
  • S — чистая площадь помещения: S = L × W.

2.1. Подбор рулона без дополнительных полос (основной случай)

Для каждой доступной ширины рулона rw из вашего списка калькулятор пробует два варианта укладки (вдоль или поперёк) и оставит лишь те, где узкая сторона помещения (с запасом) помещается в ширину рулона:

  • вариант 1: W′ ≤ rw → метраж куска = L′
  • вариант 2: L′ ≤ rw → метраж куска = W′

Для каждого подходящего варианта:

  • Площадь куска = rw × метраж
  • Остаток = Площадь куска − S
  • Стыки = 0 (помещение закрывается цельным куском)

Из всех подходящих вариантов калькулятор выбирает один, исходя из режима:

  • Минимум стыков — сначала сравнивается число стыков, при равенстве — минимальный остаток.
  • Минимум отходов — выбирается вариант с минимальным остатком, без учёта стыков.

2.2. Дополнительные полотна (когда помещение шире любого рулона)

Если ни один рулон из списка не покрывает короткую сторону помещения за один проход, калькулятор автоматически собирает помещение из нескольких параллельных полос самой широкой из ваших рулонов rw_max:

  • короткая сторона = min(L′, W′), длинная сторона = max(L′, W′)
  • число полос = округление вверх(короткая сторона / rw_max)
  • Метраж = длинная сторона (длина одной полосы)
  • Площадь куска = rw_max × Метраж × число полос
  • Остаток = Площадь куска − S
  • Стыки = число полос − 1

2.3. Округление и единицы

  • Все вычисления ведутся в метрах (длина) и квадратных метрах (площадь).
  • Для отображения в таблице все числа округляются до сотых долей (2 знака после запятой). Сами вычисления выполняются точно, без промежуточных округлений.
  • Заведённый запас всегда добавляется с двух сторон одновременно и к длине, и к ширине помещения.

3. Пример расчёта

Исходные данные:

  • Помещение: длина L = 4,20 м, ширина W = 3,35 м
  • Запас: 10 см с каждой стороны → a_m = 0,10 м
  • Доступные рулоны: 2, 2.5, 3, 3.5, 4, 5 м
  • Режим: минимум стыков

Расчёт шаг за шагом:

  1. Размеры с запасом: L′ = 4,20 + 2×0,10 = 4,40 м; W′ = 3,35 + 2×0,10 = 3,55 м.
  2. Чистая площадь: S = 4,20 × 3,35 = 14,07 м².
  3. Проверяем каждый рулон: подходят те, где одна из сторон (W′=3,55 или L′=4,40) не больше ширины рулона:
    • rw=4 м, ориентация W′=3,55≤4 → метраж=4,40 м, площадь=4×4,40=17,60 м², остаток=17,60−14,07=3,53 м², стыки=0
    • rw=5 м, ориентация W′=3,55≤5 → метраж=4,40 м, площадь=22,00 м², остаток=7,93 м², стыки=0
    • rw=5 м, ориентация L′=4,40≤5 → метраж=3,55 м, площадь=17,75 м², остаток=3,68 м², стыки=0
  4. Все варианты дают 0 стыков, поэтому в режиме «минимум стыков» выбирается вариант с минимальным остатком — это rw=4 м (остаток 3,53 м² меньше всего).
